# DevOps AI Workbench

Hands-on micro-projects that put AI to work inside real DevOps workflows: CI/CD, infrastructure as code, observability, incident response and LLMOps.

Each project is small (2-4 hours), runnable, and documented with the problem, the AI's role, the architecture, how to run it, the results and the lessons learned.

## Principles

- **Pluggable AI backend.** Every AI project supports `ollama`, `github-models` and `anthropic`; free providers are the default.
- **Cost-safe infrastructure.** Cloud work uses the free tier with a budget alert and ends with `terraform destroy`.
- **Honest record.** Commits reflect when work actually happened.

See [ROADMAP.md](ROADMAP.md) for what is planned and in progress, and [docs/tips.md](docs/tips.md) for short DevOps + AI tips.
